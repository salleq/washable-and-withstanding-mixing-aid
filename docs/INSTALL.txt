WWMA - Washable and Withstanding Mixing Aid
========================================

Free VST3 / AU plugin that tells you, in plain words, what is too much or too
little in your mix, and teaches you how to fix it yourself. Your sound passes
through untouched unless you turn on its own mastering EQ or limiter (both off
by default; it only suggests settings, you turn the knobs).

HEADS-UP: WWMA is 100 % vibe coded. It was built entirely with an AI coding
assistant, not by a seasoned plugin developer. Install and use it at your own
risk: there is no warranty, and it may have bugs. It was made in good faith, in
the hope that it helps someone make better mixes.

EASIEST: use the installer (.exe on Windows, .pkg on Mac) from the Releases page.
This zip is for installing by hand.

WHICH ZIP?
  Windows PC (Intel/AMD) ......... WWMA-Windows.zip
  Windows on ARM (Snapdragon) .... WWMA-Windows-ARM64.zip
  Mac (Intel and Apple Silicon) .. WWMA-macOS.zip (one universal build for both)
  Linux PC (x64) ................. WWMA-Linux.zip
  Linux ARM64 (e.g. Raspberry Pi 4/5 64-bit) .. WWMA-Linux-ARM64.zip
  Use the version that matches your DAW: an x64 DAW running in emulation on ARM
  Windows needs the x64 plugin.

INSTALL ON WINDOWS
1. Copy the folder "WWMA Mixing Aid.vst3" to:
   C:\Program Files\Common Files\VST3
   For CLAP hosts (Bitwig, Reaper, FL Studio...), copy "WWMA Mixing Aid.clap" to
   C:\Program Files\Common Files\CLAP
2. Rescan plugins in your DAW.

INSTALL ON macOS
1. Copy "WWMA Mixing Aid.vst3" to:
   /Library/Audio/Plug-Ins/VST3      (all users)
   or ~/Library/Audio/Plug-Ins/VST3  (just you)
   Logic Pro / GarageBand use the Audio Unit instead: copy
   "WWMA Mixing Aid.component" to /Library/Audio/Plug-Ins/Components
   CLAP hosts: copy "WWMA Mixing Aid.clap" to /Library/Audio/Plug-Ins/CLAP
2. The plugin is not notarized by Apple, so macOS blocks it at first.
   Open Terminal and run (each on one line):
   xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/WWMA Mixing Aid.vst3"
   xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/Components/WWMA Mixing Aid.component"
   (change the paths if you used your own Library folder)
3. Rescan plugins in your DAW.

INSTALL ON LINUX (x64 or ARM64)
1. Copy "WWMA Mixing Aid.vst3" to ~/.vst3 (create the folder if needed)
   or to /usr/lib/vst3 for all users.
2. For LV2 hosts (Ardour, Carla, Qtractor...), you can instead copy
   "WWMA Mixing Aid.lv2" to ~/.lv2 (or /usr/lib/lv2 for all users).
   For CLAP hosts, copy "WWMA Mixing Aid.clap" to ~/.clap (or /usr/lib/clap).
3. Rescan plugins in your DAW (Reaper, Bitwig, Ardour...).

HOW TO USE
1. Put WWMA as the LAST plugin on your master bus (after your limiter).
2. Pick a preset for your style, MIX or MASTER, and a loudness target.
3. Play the whole song (SONG), or loop the part you work on (NOW).
4. Fix the top findings one at a time. Save a snapshot before a change,
   then watch the score - and listen: your ears decide.
5. Drag a reference track (WAV, AIFF, FLAC, MP3) onto the window to compare.
   B - REF plays it at the same loudness as your mix.
